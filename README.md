# DPD601 - E-commerce analysis and late-delivery prediction (Olist)

Predicts, at the moment an order is **approved** (`order_approved_at`), whether it will be delivered on a later
calendar day than the estimated delivery date (`is_late`). Items, payment and the estimated date are assumed known
at that moment (stated limitation).

## Tools and versions
Python 3.12.10, numpy 2.5.4, pandas 3.1.1, scikit-learn 1.9.1, matplotlib 3.11.2, pytest 9.2.0, python-docx 1.2.0
(pinned in `requirements.txt`). Git for the team workflow. No notebooks.

## Structure
```
run_all.py            one entry point (audit -> clean -> merge -> features/target -> EDA -> models)
src/                  config, io_utils, audit, cleaning, merge, target, features, eda, modeling, numpy_ops
tests/                pytest suite (keys, merge, sums, target cases, forbidden columns, split order)
data/raw/             input CSVs (read-only)       data/processed/  generated by code (git-ignored)
outputs/figures|tables|audit, outputs/experiments_log.csv, outputs/results.json
docs/                 decisions_log.md (auto), feature_dictionary.md (auto), schema_diagram.md,
                      CONTRIBUTIONS.md, REVIEW_CHECKLIST.md, upstream/ (teammate's cleaning step)
report/               build_report.py -> Arabic final report (docx; pdf exported from it)
```

## Setup and run
```bash
pip install -r requirements.txt
python run_all.py
pytest -q
python report/build_report.py
```
`run_all.py` takes about one minute. Seed 42 everywhere, so results are reproducible. The report builder reads every
number from `outputs/`.

## Data note (important)
The official Ecommerce_Delivery_Project_Data package was not available; the project uses the pre-cleaned CSVs
(`*_cleaned.csv`) supplied by a teammate, placed in `data/raw/`. Those files already had missing product fields
filled with global medians and the 610 missing categories set to `unknown` (see `docs/upstream/`). Record counts match
the expected values (99,441 / 99,441 / 112,650 / 103,886 / 32,951 / 3,095 / 71). If the official zip becomes available,
replace the files in `data/raw/` (and the names in `src/config.py`) and re-run.

## Reproducing results
Everything in `outputs/` and the report is generated by the code above. The experiment log
(`outputs/experiments_log.csv`) records model, parameters, features, validation/test metrics and seed.
